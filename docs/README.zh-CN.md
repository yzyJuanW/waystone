# Waystone 文档

[English](README.md)

文档随其解释的代码和实验一起生长。首篇有价值的内容准备好时再创建分类，不维护空目录。

## 分类

- `notes/` 解释独立于单个实现的可复用概念。
- `design/` 记录 Waystone 组件的目标、约束、备选方案和设计理由。
- `decisions/` 保存具有长期影响的重要架构决策记录。
- `troubleshooting/` 保存症状、错误假设、排查过程、根因、修复方法和快速识别线索。
- `journeys/` 组织真实存在的多阶段学习路线，它是可选分类。

使用说明应贴近相关代码，放在模块 README 中；更完整的知识和设计理由放在这里。避免复制内容，应通过链接关联代码、笔记、设计、决策和排错记录。

## 何时创建独立文档

当知识很可能再次使用、横跨多个实验、无法用 README 中几段话说清、包含有意义的权衡，或记录了一次困难的排错经验时，通常值得创建独立文档。小型观察可以留在实验 README 中。

## 语言与命名

公共入口、规范和明确维护为双语的文档，以无后缀英文文件为主版本。中文配对文件使用 `.zh-CN.md`，双方在顶部互相链接。普通知识笔记可采用最适合主题的语言；文件名和关键技术术语保持英文。

决策记录格式见 [decisions/README.zh-CN.md](decisions/README.zh-CN.md)。
